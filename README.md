# 📊 Customer Analytics Dashboard (Excel VBA + AI-Assisted Development)

An Excel VBA macro that automatically builds a complete, interactive 
Customer Analytics Dashboard — Pivot Tables, KPI cards, charts, and 
slicers — from raw lead/CRM data with a single click.

## 📌 Overview
This project demonstrates AI-assisted VBA development: a detailed, 
structured prompt was engineered to generate a single, idempotent VBA 
module that builds the entire dashboard from scratch — no manual pivot 
table creation, no manual formatting.

## 🎯 What It Does
- Converts raw CRM data into a structured Excel Table
- Builds 6 Pivot Tables (Trend, Agent, Region, Product, Conversion, KPI)
- Calculates key metrics via Named Ranges (Total Revenue, Total Leads, 
  Avg Revenue/Lead, Conversion Rate, Unique Agents)
- Draws a fully formatted Dashboard sheet: header banner, KPI cards, 
  line chart, bar charts, donut chart, and slicers
- Idempotent — running it again rebuilds the dashboard cleanly without 
  duplicate sheets or errors

## 🛠️ Tools & Skills Used
- Excel VBA (PivotTables, PivotCharts, Named Ranges, Slicers)
- Structured Prompt Engineering for AI-assisted code generation
- Dashboard UI Design (KPI cards, color-coded visuals)
- Data Modeling (Excel Tables, SUMPRODUCT formulas)

## 📊 Dashboard Features
- Total Revenue, Total Leads, Avg Revenue/Lead, Converted Leads, 
  Conversion Rate, Unique Agents (KPI cards)
- Revenue Trend by Month (Line Chart)
- Top Performing Agents (Bar Chart)
- Revenue by Region & Product/Service
- Conversion Breakdown (Donut Chart)
- Interactive Slicers: Year, Customer Type, Product/Service

## 💡 Skills Demonstrated
- VBA Macro Programming (no Select/Activate — direct object referencing)
- Prompt Engineering for AI-assisted development
- PivotTable & PivotChart Automation
- Dashboard Design & Data Visualization
- Idempotent, error-safe code design

## 🚀 How to Use
1. Open the workbook containing a `Customer_Data` sheet with lead/CRM data
2. Run the `BuildCustomerAnalyticsDashboard` macro
3. The Dashboard and Pivot sheets are generated automatically
